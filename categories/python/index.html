1、安装

1

pip install pipreqs

2、生成项目依赖

进入项目根目录

1

pipreqs . --encoding=utf8 --force

说明

参数 说明
–force 会覆盖前一个requirements.txt
–encoding=utf8 解决编码问题

plt.rcParams['font.sans-serif'] = ['SimHei']

plt.rcParams['font.weight'] = 'normal'
